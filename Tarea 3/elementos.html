1. Tipografía y Texto

Clases para dar estilo a textos, encabezados y párrafos sin escribir CSS.

Encabezados y Displays
.h1 a .h6 - Aplican estilos de encabezado a cualquier elemento.
.display-1 a .display-6 - Encabezados más grandes y llamativos para secciones destacadas.

h1. Título principal

h2. Título secundario

h3. Subtítulo

h4. Encabezado

h5. Encabezado
h6. Encabezado

Display 1

Display 4

Display 6

CÓDIGO
<!-- Encabezados -->
<h1>h1. Título principal</h1>
<h2>h2. Título secundario</h2>
<!-- Displays -->
<p class="display-1">Display 1</p>
<p class="display-4">Display 4</p>
Clases de Texto
.lead - Destaca un párrafo introductorio.
.text-muted - Texto atenuado (gris).
.text-primary, .text-success, .text-danger - Colores contextuales.
.text-center, .text-end - Alineación horizontal.
.text-uppercase - Transforma a mayúsculas.
.fw-bold, .fst-italic - Negrita y cursiva.

texto en mayúsculas

<!-- Clases de texto -->
<p class="lead">Texto destacado</p>
<p class="text-primary">Texto azul</p>
<p class="text-center text-uppercase fw-bold">Texto combinado</p>

2. Listas

Clases para estilizar listas, eliminar viñetas o hacerlas horizontales.

Lista Normal
Sin clases especiales, Bootstrap respeta el estilo nativo del navegador.
  • Elemento 1
  • Elemento 2
  • Elemento 3
CÓDIGO
<ul>
  <li>Elemento 1</li>
  <li>Elemento 2</li>
</ul>
Lista sin viñetas .list-unstyled
.list-unstyled - Elimina viñetas y margen izquierdo.
  • Elemento sin viñeta
  • Otro elemento
  • Y otro más
CÓDIGO
<ul class="list-unstyled">
  <li>Elemento sin viñeta</li>
</ul>
Lista horizontal .list-inline
.list-inline - Convierte la lista en horizontal.
.list-inline-item - Se aplica a cada <li>.
  • Inicio
  • Servicios
  • Contacto
CÓDIGO
<ul class="list-inline">
  <li class="list-inline-item">
    <span class="badge bg-primary">Inicio</span>
  </li>
</ul>
Lista de descripción
Usa <dl>, <dt> (término) y <dd> (definición).
HTML
Lenguaje de marcado para estructurar contenido web.
CSS
Hojas de estilo para dar diseño y presentación.
JavaScript
Lenguaje de programación para agregar interactividad.
CÓDIGO
<dl>
  <dt>HTML</dt>
  <dd>Lenguaje de marcado...</dd>
</dl>

3. Tablas

Clases para estilizar tablas con diferentes estilos y hacerlas responsivas.

Tabla básica .table
.table - Clase base para estilizar cualquier tabla.
.table-striped - Alterna colores en filas (cebras).
.table-hover - Efecto hover al pasar el mouse.
.table-dark - Fondo oscuro para el encabezado.
# Nombre Email Rol
1 Ana García ana@email.com Admin
2 Carlos Pérez carlos@email.com Usuario
3 Laura Martínez laura@email.com Editor
CÓDIGO
<table class="table table-striped table-hover">
  <thead class="table-dark">
    <tr><th>#</th><th>Nombre</th></tr>
  </thead>
  <tbody>
    <tr class="table-warning">...</tr>
  </tbody>
</table>
Tabla con bordes y compacta .table-bordered .table-sm
.table-bordered - Añade bordes a todas las celdas.
.table-sm - Reduce el padding para una tabla más compacta.
.table-success, .table-danger - Colores contextuales para filas.
Producto Precio Stock
Laptop $1,200 Disponible
Mouse $25 Bajo stock
Teclado $80 Agotado
CÓDIGO
<table class="table table-bordered table-sm">
  <thead class="table-success">...</thead>
  <tbody>
    <tr><td>Laptop</td><td>$1,200</td></tr>
  </tbody>
</table>

4. Imágenes

Clases para hacer imágenes responsivas, redondas, circulares o con borde.

Imagen responsiva .img-fluid
.img-fluid - Hace la imagen responsiva (max-width: 100%; height: auto;).
Se escala dentro de su contenedor sin exceder su tamaño original.
CÓDIGO
<img src="foto.jpg" class="img-fluid" alt="Imagen responsiva">
Formas de imagen
.rounded - Esquinas redondeadas.
.rounded-circle - Forma circular (ideal para avatares).
.img-thumbnail - Añade borde y padding (como miniatura).

.rounded

.rounded-circle

.img-thumbnail

CÓDIGO
<!-- Imagen circular (avatar) -->
<img src="avatar.jpg" class="rounded-circle img-fluid" width="150">
<!-- Miniatura con borde -->
<img src="foto.jpg" class="img-thumbnail">
Figure (con pie de foto) .figure
.figure - Contenedor para imagen con pie.
.figure-img - Aplica a la imagen dentro de figure.
.figure-caption - Pie de foto con estilo.
CÓDIGO
<figure class="figure">
  <img src="foto.jpg" class="figure-img img-fluid rounded">
  <figcaption class="figure-caption">Pie de foto</figcaption>
</figure>
Imagen flotante .float-start / .float-end
.float-start - Flota a la izquierda.
.float-end - Flota a la derecha.
.me-3 / .ms-3 - Margen derecho/izquierdo para separar del texto.

Esta imagen flota a la izquierda con .float-start y tiene un margen derecho con .me-3. El texto fluye a su alrededor.

Esta imagen flota a la derecha con .float-end y tiene un margen izquierdo con .ms-3.

CÓDIGO
<!-- Imagen flotante a la izquierda -->
<img src="foto.jpg" class="float-start me-3 rounded">
<div class="clearfix"></div> <!-- Limpia el flotado -->

5. Formularios

Clases para estilizar todos los elementos de formularios de forma consistente.

Formulario básico
.form-control - Estilo base para inputs, textarea y select.
.form-label - Estilo para etiquetas.
.form-text - Texto de ayuda debajo del input.
.mb-3 - Margen inferior entre campos.
Ingresa tu nombre completo sin abreviaturas.
CÓDIGO
<!-- Campo de texto -->
<div class="mb-3">
  <label class="form-label" for="nombre">Nombre</label>
  <input type="text" class="form-control" id="nombre">
  <div class="form-text">Texto de ayuda</div>
</div>
Validación y grupos de entrada .is-valid .input-group
.is-valid / .is-invalid - Estados de validación.
.valid-feedback / .invalid-feedback - Mensajes de validación.
.input-group - Agrupa input con texto o botón.
.input-group-text - Texto o ícono dentro del grupo.
¡El dato es correcto!
Por favor, ingresa un dato válido.
años
CÓDIGO
<!-- Validación -->
<input class="form-control is-valid">
<div class="valid-feedback">Correcto</div>
<!-- Input Group -->
<div class="input-group">
  <span class="input-group-text">$</span>
  <input class="form-control">
</div>
<!-- Switch -->
<div class="form-check form-switch">
  <input class="form-check-input" type="checkbox">
</div>

6. Botones

Clases para crear botones con diferentes colores, tamaños y estados.

Colores sólidos .btn-*
.btn - Clase base para todos los botones.
.btn-primary, .btn-success, .btn-danger - Colores contextuales.
.btn-secondary, .btn-warning, .btn-info, .btn-light, .btn-dark - Más colores.
CÓDIGO
<button class="btn btn-primary">Primario</button>
<button class="btn btn-success">Éxito</button>
Outline .btn-outline-*
.btn-outline-primary, .btn-outline-success - Botones con borde y fondo transparente.
CÓDIGO
<button class="btn btn-outline-danger">Peligro</button>
Tamaños .btn-lg .btn-sm
.btn-lg - Botón grande.
.btn-sm - Botón pequeño.
CÓDIGO
<button class="btn btn-primary btn-lg">Grande</button>
<button class="btn btn-primary btn-sm">Pequeño</button>
Estados .active .disabled
.active - Apariencia de botón presionado.
.disabled - Botón deshabilitado (no interactivo).
spinner-border - Indicador de carga.
CÓDIGO
<button class="btn btn-primary active">Activo</button>
<button class="btn btn-primary disabled" disabled>Deshabilitado</button>
Botones con íconos
Usa Bootstrap Icons dentro del botón.
Los íconos pueden ir antes o después del texto.
CÓDIGO
<button class="btn btn-success">
  <i class="bi bi-check-circle"></i> Aceptar
</button>
Grupos de botones .btn-group
.btn-group - Agrupa botones horizontalmente.
Útil para paginación o acciones relacionadas.
CÓDIGO
<div class="btn-group" role="group">
  <button class="btn btn-outline-primary">1</button>
  <button class="btn btn-outline-primary active">2</button>
</div>
Botones de ancho completo .d-grid
.d-grid - Convierte el contenedor en grid.
.gap-2 - Espaciado entre botones.
CÓDIGO
<div class="d-grid gap-2">
  <button class="btn btn-primary">Ancho completo</button>
</div>
