2.3. Manejo de Eventos

Click, hover, focus, keyup, submit y mas

Evento Click

Se dispara al hacer clic.

Esperando clic...
CODIGO
// Evento click
$('#btnClickDemo').on('click', function() {
  $('#resultadoClick').html('Clic detectado');
});

Evento Hover

Se dispara al entrar y salir con el mouse.

Pasa el mouse aqui

Esperando hover...
CODIGO
// Evento hover
$('#hoverDemo').hover(
  function() { // mouseenter
    $('#hoverTexto').text('Dentro!');
  },
  function() { // mouseleave
    $('#hoverTexto').text('Has salido');
  }
);

Focus / Blur

Se disparan al enfocar y desenfocar un input.

Enfoca el input...
CODIGO
// Eventos focus / blur
$('#inputFocus').on('focus', function() {
  $('#resultadoFocus').html('Input enfocado');
}).on('blur', function() {
  const valor = $(this).val() || 'vacio';
  $('#resultadoFocus').html('Valor: ' + valor);
});

Evento Keyup

Se dispara al soltar una tecla.

Escribe algo...
CODIGO
// Evento keyup
$('#inputKeyup').on('keyup', function() {
  const texto = $(this).val();
  const cantidad = texto.length;
  $('#resultadoKeyup').html('Texto: "' + texto + '" — ' + cantidad + ' caracteres');
});

Evento Submit

Se dispara al enviar un formulario.

Completa el formulario y envia...
CODIGO
// Evento submit
$('#formSubmit').on('submit', function(e) {
  e.preventDefault();
  const nombre = $('#submitNombre').val();
  const email = $('#submitEmail').val();
  $('#resultadoSubmit').html('Formulario enviado por ' + nombre + ' (' + email + ')');
  this.reset();
});

Efectos Fade

Desvanecimiento suave de elementos.

Elemento con fade
CODIGO
// Efectos Fade
$('#btnFadeIn').on('click', function() {
  $('#cajaFade').fadeIn(600);
});
$('#btnFadeOut').on('click', function() {
  $('#cajaFade').fadeOut(600);
});
$('#btnFadeToggle').on('click', function() {
  $('#cajaFade').fadeToggle(600);
});
$('#btnFadeTo').on('click', function() {
  $('#cajaFade').fadeTo(400, 0.5);

Elemento con slide

Animaciones con .animate()

Crea animaciones personalizadas con propiedades CSS.

Mover
Haz clic en un boton para ver la animacion
CODIGO
// Animaciones personalizadas con .animate()
$('#btnAnimMove').on('click', function() {
  $('#cajaAnimate').animate({ marginLeft: '150px' }, 600);
});
$('#btnAnimSize').on('click', function() {
  $('#cajaAnimate').animate({
    width: '180px',
    height: '180px',
    borderRadius: '50%'
  }, 600);
});
$('#btnAnimRotate').on('click', function() {
  $('#cajaAnimate').animate({ opacity: 0.2 }, 300)
    .animate({ opacity: 1 }, 300);
});

2.5. Manipulacion del DOM

Agregar, eliminar, modificar y clonar elementos

.html() y .text()

Modificar el contenido HTML o texto de un elemento.

Contenido original

Haz clic en un boton...

.append() y .prepend()

Agregar elementos al final o al inicio.

Elemento existente 1
Elemento existente 2

Elemento 1 remove
Elemento 2 remove

2.6. Ajax

Peticiones HTTP con $.ajax(), $.get(), $.post() y $.getJSON()

$.ajax()

Metodo completo para peticiones HTTP.

Haz clic en un boton...

CODIGO
// $.ajax()
$.ajax({
  url: 'https://jsonplaceholder.typicode.com/users',
  method: 'GET',
  success: function(data) { // Procesar datos },
  error: function(xhr) { // Manejar error }
});

$.get() · $.post() · $.getJSON()

Metodos abreviados para peticiones comunes.

Haz clic en un boton...

CODIGO
// $.getJSON()
$.getJSON('https://jsonplaceholder.typicode.com/users/1', function(data) {
  // Procesar datos
});

// $.post()
$.post('https://jsonplaceholder.typicode.com/users',
  { nombre: 'Juan', email: 'juan@email.com' },
  function(data) { // Procesar respuesta }
);
